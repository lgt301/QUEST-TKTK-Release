# QUEST-TKTK

Bản phát hành **QUEST-TKTK** (Truyền Kỳ Tái Khởi).

**Tải bản mới nhất:** [Releases → Latest](https://github.com/lgt301/QUEST-TKTK-Release/releases/latest) — file `QUEST-TKTK.zip`.

- Cần key để chạy: mở tool, gửi mã máy cho người bán để nhận key.
- Hướng dẫn cài đặt, kích hoạt và xử lý lỗi: `HUONG_DAN.txt` trong bản phát hành.
- Tool đang mở tự hiện thông báo khi có bản mới.
- Repo này chỉ chứa file phát hành, không có mã nguồn.
